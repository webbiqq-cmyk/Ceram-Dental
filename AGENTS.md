# Repository instructions

- Keep public product copy and source files free of AI tool names, assistant names, generated-by notices, and tool watermarks.
- Do not add AI assistant/tool attribution, generated-by notices, or similar branding to UI text, metadata, comments, filenames, assets, or commit-facing documentation.
- Keep changes focused, remove dead code only after checking references, and preserve the existing clinical branding and security controls.
- Before release, run syntax checks, the relevant test suite, `git diff --check`, and verify the deployed commit separately from local results.
